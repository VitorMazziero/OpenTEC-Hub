# Aplicativo do frasco agitador

Aplicativo Flutter para controle local do agitador. O firmware correspondente está em `../../firmware/flask-agitator`.

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

O potenciômetro local pode reassumir a autoridade conforme o comando `ActivePot`; consulte `../../docs/PROTOCOL.md` e valide a parada em bancada.
